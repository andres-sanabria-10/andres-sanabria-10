## 🎓 About Me

- I'm a Systems and Computer Engineering student at **Universidad Pedagógica y Tecnológica de Colombia**.
- I enjoy building **full-stack applications**, creating smart APIs powered by **AI models**, and developing automation tools using **webhooks** and **chatbots**.
- I've developed and deployed:
  - 🤖 NLP pipelines using Hugging Face Transformers (sentiment, emotion, irony, toxicity, translation)
  - 💬 WhatsApp chatbot using `wa-automate-nodejs` and webhook integration
  - ⚙️ RESTful APIs with Flask and Node.js
  - 🌐 Frontends with React and Vite
  - 📊 Data pipelines using DBT and PostgreSQL
- I'm familiar with Git, Docker, and cloud deployment platforms like Render.
